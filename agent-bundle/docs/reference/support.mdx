supaschema is free and open source under the MIT License.

Use the public project channels for reproducible questions and defects. Use the private security channel for vulnerabilities.

## Channels

- Public bugs and feature requests belong in [GitHub issues](https://github.com/jmclaughlin724/supaschema/issues).
- Usage questions can start in a GitHub issue when the answer can be public and reproducible.
- Security vulnerabilities belong in the [private advisory flow](https://github.com/jmclaughlin724/supaschema/security/advisories/new).

Do not include secrets, database URLs, customer data, private schema dumps, or other confidential material in public issues.

## Boundaries

Project support is community-maintained and best-effort; no response time or service level is promised. Check the [support matrix](/reference/support-matrix), search existing issues, and include a minimal reproduction that removes private data.
