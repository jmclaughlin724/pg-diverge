supaschema is distributed as an npm package and works in Node.js projects that target PostgreSQL 15+ directly or through managed PostgreSQL platforms such as Supabase, Neon, AWS RDS/Aurora PostgreSQL, Google Cloud SQL/AlloyDB, Azure Database for PostgreSQL, Render, Railway, Heroku Postgres, Timescale, Crunchy Bridge, and EDB.

## Requirements

| Requirement | Minimum |
| --- | --- |
| Node.js | 22.12.0 |
| PostgreSQL target | 15 |

The PostgreSQL parser is bundled with the package through `libpg-query`, so you do not need a local PostgreSQL server to generate migrations from SQL files or Git refs.

<Note>
  Supabase is not the only supported target. Install recognizes common project markers for Neon, RDS/Aurora PostgreSQL, Cloud SQL, AlloyDB, and Azure PostgreSQL, and every PostgreSQL provider can use named `environments` or `SUPASCHEMA_DATABASE_URL` for database URL resolution.
</Note>

## Install

Use npm in this repository and in projects that follow the supaschema package guidance:

```bash
npm install --save-dev supaschema
```

Other package managers can install the package, but this repository uses npm and `package-lock.json`.

## Verify the binary

```bash
npx supaschema --version
```
