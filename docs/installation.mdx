supaschema is distributed as an npm package and works in Node.js projects that target PostgreSQL or Supabase.

## Requirements

| Requirement | Minimum |
| --- | --- |
| Node.js | 22.12.0 |
| PostgreSQL target | 15 |

The PostgreSQL parser is bundled with the package through `libpg-query`, so you do not need a local PostgreSQL server to generate migrations from SQL files or Git refs.

## Install

Use npm in this repository and in projects that follow the supaschema package guidance:

```bash
npm install --save-dev supaschema
```

Other package managers can install the package, but this repository uses npm and `package-lock.json`.

## Verify the binary

```bash
npx supaschema --version
```
