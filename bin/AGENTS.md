# bin/ — runtime entry scripts

Standalone `.mjs`/`.cjs` scripts that run without the TypeScript build, plus the published CLI entry.

## Contents

- `supaschema.cjs` — published CLI entry (`package.json#bin.supaschema`)
- `scaffold.mjs` — `supaschema init` project scaffolding
- `config-contract.mjs` — generated mirror of `src/config-contract.ts` (bootstrap-safe; regenerated by `scripts/check-schema.mjs`, parity enforced by `check-config-standardization.mjs`)

## Owners

- Package boundary and scaffold: `.claude/rules/13-npm-package-boundary.md`
- Version control and release: `.claude/rules/19-version-control-release.md`
- Verify: `npm run check:package`, `npm pack --dry-run --json`
